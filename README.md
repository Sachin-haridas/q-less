# Q-less

Q-less is an OCR-based canteen food booking system developed using React, Node.js, Express.js, and MongoDB. The platform streamlines food ordering and automates UPI payment verification using Tesseract OCR.

## Features

- User authentication and authorization
- Food menu management
- Order placement and tracking
- OCR-based UPI payment screenshot verification
- Automatic payment validation workflow
- Admin order management
- Real-time order status updates
- RESTful API architecture
